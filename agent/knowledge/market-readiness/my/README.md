# 市场就绪度 v0.1（马来西亚）

> 这一层只回答一个问题：**页面上有没有把进入马来西亚市场所需的信息讲清楚。**
> 不是合规检查、不是认证核验、不打分。法律判断归 `knowledge/legal/my/` 的合规规则库。

## 8 条固定检查

实现：`agent/src/market-readiness/analyze.ts`（代码侧，不经模型）；规则元数据在
`agent/src/market-readiness/rules.ts`。同一份页面文本跑两遍结果完全一致。

| checkId | 检查 | 取证范围 | 判 `present` 的条件 |
|---|---|---|---|
| `MY-MR-01` | 英语变体一致性 | 整页正文（排除导航/页脚标签） | 未命中美式拼写清单，也没有未翻译中文 |
| `MY-MR-02` | 货币与价格呈现 | 商品主面板 | 出现 `RM`/`MYR` 报价，且有 SST/GST 含税或未税说明 |
| `MY-MR-03` | 计量单位（公制） | 商品主面板 | 出现公制单位（cm/kg/ml/L/W/V），且无英制混用 |
| `MY-MR-04` | 电压与插头 | 商品主面板 | 同时写明 230V/50Hz 类电压与 Type G/三脚插头 |
| `MY-MR-05` | 本地联系方式 | 整页（页脚也算） | 有马来西亚本地电话 + 地址或工作时间 |
| `MY-MR-06` | 配送、退换与保修 | 整页正文 | 三块都有可读的句子（不只是导航链接） |
| `MY-MR-07` | 本地支付方式 | 整页正文 | 点名 FPX / 本地银行 / 本地电子钱包 |
| `MY-MR-08` | 认证标志展示 | 整页 | 出现 SIRIM / Safety Mark / MCMC 等标志名或编号 |

## 四种状态

| status | 含义 | 使用规则 |
|---|---|---|
| `present` | 页面写到了这条信息 | 必须给出页面原文 `quote` |
| `missing` | 页面没有写 | `quote` 留空，不补写、不推测 |
| `needs_review` | 写到了但不完整 / 只给了笼统说法 | `quote` 给已展示的部分，`why` 说明缺什么 |
| `not_applicable` | 本页或本品类不涉及 | `why` 必须说明为什么不适用（例如非商品页、非电器品类） |

四条都不是风险等级，也没有 severity：报告不把它折算进高/中/低风险数量。

## 取证口径（避免导航/页脚误报）

1. **商品主面板**：优先用「带小数点的价格」作锚点（跳过 `RM 0.00` 这类购物车小计，
   优先紧邻 SKU / 加购按钮的报价），向前只并入句子、SKU、型号或带规格线索的行，
   向后到「Recommended Product / You may also like / Reviews」为止。
   推荐位里的 `75-inch`、分类导航里的 `Wireless Chargers` 因此不会算到被诊商品头上。
2. **整页检查**（联系方式、支付、认证、配送）只看「像句子」的行：
   没有功能词、没标点、≤6 个词的短标签（`Delivery`、`Returns & Refunds`、`Warranty`）
   是导航/页脚链接，不算「页面已经说明」。被拆行截断的碎片（`Free Delivery * with`）也不算。
3. **引用**：`quote` 必须是页面文本的逐字子串（允许跨行），超过 180 字符按句末或词边界截断，
   截断后仍要包含命中词；页面没展示就留空。
4. **措辞**：不出现「合法 / 违法 / 保证通过 / 已认证」等结论性说法；认证只记录「是否展示」，
   不核验证书真伪（验证归合规规则库与人工复核）。

## 输出位置

- 报告 JSON：`market_readiness`（固定 8 条，允许 `not_applicable`），同时给
  `dimensions` 追加一行「市场就绪度」，`note` 只写数量（已展示/未展示/需复核/不适用）。
- 顶层 `not_assessable` 会追加一条能力边界：不核验认证真伪、不判断税务与支付合规。
- 网页与 Typst PDF 都在「诊断维度」之后、风险清单之前单独成章（RAY-697）。
- 8 条检查**不进** `risks`，也不进风险计数。

## 已知限制

- 只读单页可见文本：结算页、配送页、FAQ 里的信息不在本页时一律记「页面未展示」。
- 不判断认证真伪、不判断价格含税是否正确、不判断支付通道是否可用。
- 品类适用性：电压/插头与认证展示只对 `small_appliances`、`consumer_electronics`、
  `beauty_personal_care`、`home_living` 生效；其余品类记 `not_applicable`。
- 页面用 JS 延迟渲染价格/规格时，静态抓取可能抓不到；报告以抓取时可见文本为准。
