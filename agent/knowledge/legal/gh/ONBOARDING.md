# 加纳（GH）v0.1 — 一页接入建议

**结论：可开放「受限版（beta）」，不具备全面开放条件。** 页面级可判的是电商披露（ETA 2008 s.47）、通用标签要素与英文义务（L.I. 1541）、隐私告知（DPA 2012）；不能自动判认证状态、GSA 强制性标准适用性、能效注册与实物标签。所有 high 级 finding 默认附「需专业审核」。

## 1. 规则构成

| 指标 | 数量 | 占比 |
| --- | --- | --- |
| 总规则 | 33 | 100% |
| `rule_level` | 29 | 88% |
| `substantiation` | 1 | 3% |
| `human_review` | 3 | 9% |
| `review_required: true` | 4 | 12% |
| 覆盖法规/指南 | 10 部/套 | — |
| `confidence = medium` | 1 | 3%（`GH-CERT-07` EasyPASS 执行机构） |

- `rule_level`：ETA s.47 十项披露与 14 日取消权（10 条）、L.I. 1541 标签与英文（4 条）、FDA 标签指南（4 条）、PHA 851 注册/指南效力（2 条）、GSA Act s.33(2)（1 条）、NCA 型式批准与标记（4 条）、L.I. 1815 能效（1 条）、DPA 2012（5 条）。
- `substantiation`：`GH-LAB-10`（L.I. 1541 r.3(f) 电气特性：电池容量、功率、降噪深度、蓝牙版本等数值）。
- `human_review`：`GH-ETA-02`（描述是否充分）、`GH-LAB-09`（PHA 851 s.113 误导性标签/广告）、`GH-LAB-11`（标签「准确」判断）。

## 2. 必须人工审的条目（4 条 + 2 条高风险）

| 条目 | 为什么必须人工审 |
| --- | --- |
| `GH-ETA-02` | 「高端/专业/原装」是否构成充分描述，取决于整体页面与规格可核性 |
| `GH-LAB-09` | PHA 851 s.113 的「虚假、误导、欺骗」需语境与证据；且只覆盖 FDA 五类产品 |
| `GH-LAB-11` | 「信息充分且准确」是标准型表述，无法凭词表定性 |
| `GH-CERT-07` | EasyPASS 执行机构存疑（Bureau Veritas → GSA？），报告不得写机构名 |
| `GH-LAB-01`（`review_required=true`） | 附表一覆盖面广，误判会影响整份报告；涉及到港扣留 |
| `GH-CERT-01`（`review_required=true`） | 强制性标准清单未取得，只能条件式表达；违反属犯罪 |

**可先自动筛查、但仍需证据的 25 条**：其余规则 `review_required=false`，报告只能写「页面事实 + 需核实项」，不得写终局结论。

## 3. 开放条件（建议 v0.2 的门槛）

1. **GSA 强制性标准清单**：取得公报通告与现行清单，把 `GH-CERT-01` 从条件式改为逐品类可判。
2. **EasyPASS 现行执行安排**：确认 2026 年后由谁签发 CoC，更新 `GH-CERT-07` 并去掉 medium。
3. **L.I. 1958 / L.I. 2353**：取得冰箱与 LED/自镇流灯能效条文，补齐能效覆盖。
4. **DPC 指引**：登记范围、域外适用、泄露通知（s.31），补齐隐私规则。
5. **《Consumer Protection Bill》进展**：若通过，全库需重写「无统一消保法」的判断与 `human_review` 规则。
6. **本地律师复核**：4 条 `review_required` + 3 条 `human_review` 至少完成一轮抽样；尤其 PHA s.113 与 NCA 型式批准的适用边界。

## 4. 试点建议

- **可试点**：小家电/3C 商品页的 ETA s.47 披露完整性（主体信息、完整价格、交付时间、退换政策、隐私政策入口）；标签要素与英文义务的「页面/实物待核」提示；订阅/营销的同意与告知检查。
- **不可试点**：NCA 型式批准状态核验、GSA 强制性标准符合性、能效注册、EasyPASS 办理状态、实物标签真伪。
- **报告门槛**：每条 finding 带 `rule_id`、页面证据、证据缺口、`decision_level`；`review_required=true` 统一加「**需专业审核**」；缺证写「页面未展示，需向商家核实」，不推断「未认证/不合规」。
- **免责声明**：保留「基于公开法规的自动筛查，不构成法律意见」。

## 5. 风险提示

- 加纳**没有统一的消费者保护法**，没有 ACL s.18 式总兜底条款；把 MY/AU/UK 的「误导性广告」话术直接搬过来会过度断言。
- 来源结构特殊：无公开的统一立法数据库；Act 843 与 Act 1078 为扫描件，引文经 OCR + 目视校对（见 `SOURCES.md` X4/X5）。
- 罚则只写上限；除 NCA 的 GhC20,000–50,000 与 L.I. 1815 的 250 penalty units 外，本版未核到可引用的具体数额。
- 执法实践（GSA 扣留、FDA 注册整改、DPC 执法）缺少公开数据，不预测实际结果。
