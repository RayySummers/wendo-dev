# 南非（ZA）合规规则库 v0.1

> 支撑 RAY-684「合规与风险（Layer 4）」与 RAY-726「南非 v0.1」。
> 本文件是**人工阅读版**：关键发现、覆盖矩阵、open questions、报告措辞模板、接入建议。
> 机器可读规则见 `rules.v0.1.json`（41 条），来源与哈希见 `SOURCES.md`，样例见 `SAMPLE_FINDINGS.md`。

## 一句话结论

南非**具备开放条件**，但必须带三个限制上线：① 线上交易与线下营销适用**两部不同的法**（ECTA 第 7 章 vs CPA），报告不能混引；② 认证与准入的法律依据齐全，但**发证机关的细则本版没拿到**（ICASA 站点不可达、NRCS 强制规范清单页为空），报告只能写到「须取得授权书/型号核准」这一层；③ 41 条里 23 条须人工/律师复核后才能进结论，自动化只能用来**提示风险**，不能用来下判断。

## 关键发现（8 条）

1. **两部法按渠道分工，不是叠加**。CPA 有 4 处明文把线上交易让给 ECTA：s.16(1)（撤销权）、s.23(1)(b)（价格披露）、s.26(1)(a)（交易记录）、s.33(1)(b)（目录销售）。同一页面同时引用 CPA s.23 与 ECTA s.43 会**重复计分且互相矛盾**（一个要求展示价，一个要求含运费税费的完整价）。
2. **没有「必须用英语」的法条**。唯一的通用语言义务是 CPA s.22 的「平实语言」——效果标准，不是语种标准。南非有 12 种官方语言，写成「南非法律要求英语」是错的。真正的抓手是 s.40(2)：明确把「无法理解协议语言」列为不合良心行为的考量因素。
3. **认证是「双轨」**：小家电走 NRCS 强制规范 + 授权书（LOA，**进口前**取得）；带蓝牙/Wi-Fi 的 3C 走 ICASA 型号核准（ECA s.35(1)）。两条互不替代，一个产品可能两张证都要。
4. **LOA 与「CE/SABS 标志」不是一回事**。s.41(3)(a) 专门禁止虚假的「地位/批准」陈述——把「工厂有证」写成「产品获政府认证」是中国卖家在南非最常见的可诉表述之一。
5. **6 个月默示保证不能靠「注册」条件化**。s.56(2) 的退货修换权是法定的，s.56(4) 明确与明示保证并存；把保修写成「注册后生效」可能落入 s.51(1)(b)(i) 的禁止条款。
6. **原产地强制说明不覆盖家电**。s.24(4)-(5) 的指定商品只有纺织品/服装/鞋/皮革（Regs reg.6）与转基因生物（reg.7）。家电/3C 的「Made in China」属自愿陈述，但一旦写了就受 s.41 约束。
7. **直销是 opt-in**。POPIA s.69(1) 原则上禁止未同意的电子直销；预勾选同意无效（s.11(2)(a)）。ECTA s.45 另有一套「退订 + 信息来源」义务，两条并行。
8. **计量单位是硬门槛**。LMA s.34(4)：进口商品的数量的标示若用规定以外的单位，须同时给出 SI 等值，否则不得进口。中文包装只写「斤/寸」是真实的清关风险，不只是文案问题。

## 字段与判定口径

字段定义与 `agent/knowledge/legal/README.md` 一致，本市场另加两个约定：

- `applies_when` **未实现**（字段尚不存在），因此「适用性」写在 `requirement` 首句或 `penalty_or_note` 里。这是 v0.2 要补的第一个字段（见 SAMPLE_FINDINGS 的 FP1）。
- `confidence=medium` 的 3 条（ZA-ACC-03/04/05）全部是**生效日未取得公告**（ECA、LMA）的条目，条文本身已与公报原文逐字核对，不影响引文准确性。

## Open questions

1. **ICASA 型号核准的程序与豁免清单**：站点在本环境不可达（TLS 与 HTTP 两种方式各失败一次），ECA s.35(2) 允许对已获 ETSI 等机构核准的设备免除核准，但豁免清单在 ICASA 公告里，未取得。→ 报告不得描述具体流程与时效。
2. **NRCS 强制规范清单（VC 编号）**：官网「Compulsory Specifications」相关页面为空壳，未取得 VC 清单与最新公告；因此规则只写「适用强制规范的商品」，不写具体编号。家电对应的 SANS 60335 系列为付费标准，未取得全文。
3. **CPA 与 ECTA 是否有修订**：gov.za 只提供签署版公报，未取得官方合并文本（consolidation）。若 2009/2002 年之后有条文修订，本版可能存在版本滞后。
4. **LMA 生效日**：s.43 规定由总统公告确定，公告未取得；`effective_date` 暂记公报日 2014-05-19。
5. **ECA 全面生效日**：同上，暂记 2006-07-19。
6. **s.24(4) 的指定商品是否扩及家电**：本版依 Regs reg.6/reg.7 判定为「仅纺织/服装/鞋/皮革 + GMO」，若部长后续公告扩围，需更新 ZA-DIS-09。
7. **能效标示**：南非对部分家电有强制能效标示要求，本版未取得官方来源，未建规则。
8. **一次性医疗器械式的「医疗/杀菌」声称边界**：页面若出现「杀菌 99.9%」「医疗级」，除 CPA s.41 外可能触及卫生部的消毒剂/医疗器械管辖，本版未研究。
9. **省级/市级消费者条例**：未覆盖（南非消费者保护以国家法为主，但地方条例存在）。
10. **ARB 广告准则**：行业自律（非官方），按来源纪律未收；实际执法中广告主仍会受其约束，报告可提示但不作依据。

## 报告措辞模板

**总则**：不出现法律定性结论；只说「根据 <法> <条>，这类表述受何种要求约束」「页面未展示什么」「需要什么证据/找谁核实」。高风险条目一律加「需专业审核」。

| 场景 | 模板 |
| --- | --- |
| 认证/批准类陈述 | 「页面称 <原文>。根据南非消费者保护法 s.41(3)(a)，供应者不得就自身拥有的批准或地位作出虚假陈述。请提供该认证的证书编号、持证人名称与覆盖型号清单，以确认该陈述是否适用于本产品。需专业审核。」 |
| 功效/健康类 | 「页面称 <原文>。根据 s.41(3)(b)(i)，商品的益处与性能特征属于可诉事实陈述；此类功效表述在南非属需证明的陈述。请提供检测报告（标准号、样品型号、测试条件）。需专业审核。」 |
| 价格与折扣 | 「页面展示 <划线价/折扣>。根据 s.41(3)(f)，价格优势须真实存在；s.23(11) 另规定减价与展示价的折算方式。请提供促销前后的成交价记录与基准价持续时间。需专业审核。」 |
| 线上披露缺失 | 「页面未展示 <法定名称/注册号/实体地址/含运费税费的完整价格>。若该站直接接受线上下单，南非 ECTA s.43(1) 要求披露上述信息；未披露时消费者取得 14 日撤销权。页面未展示，需向商家核实。」 |
| 认证信息缺失 | 「页面未展示 NRCS 授权书编号、SABS 标志或 ℮ 数量标记。缺失本身不构成违规，需向商家核实其是否已取得相应授权与标记。」 |
| 保修条件化 | 「页面将保修与产品注册绑定。南非消费者保护法 s.56(2) 的 6 个月默示保证不因未注册而消灭，s.51(1)(b)(i) 禁止剥夺消费者法定权利的条款。建议核对保修条款全文。需专业审核。」 |
| 语言可读性 | 「页面为英文，含 <术语密度/长句/缩写>。s.22 要求以目标消费者可理解的平实语言呈现；南非法不要求特定语种，但要求可理解。需人工评估目标读者。需专业审核。」 |
| 结尾声明 | 「以上为基于公开法规的自动筛查，不构成法律意见。」（措辞由产品定稿） |

## 接入建议（一页）

**规则构成**

| decision_level | 条数 | 占比 | 含义 |
| --- | --- | --- | --- |
| `rule_level` | 32 | 78% | 法条 + 页面原文同时成立即可给出规则级提示 |
| `substantiation` | 4 | 10% | 只能判「需要证明」，不能判真假 |
| `human_review` | 5 | 12% | 需人工/律师判断（整体印象、平实语言、不合理手段、安保充分性） |
| 合计 | 41 | 100% | 其中 `review_required=true` 23 条（56%） |

**必须人工审的 23 条**（`review_required=true`）：全部 `substantiation` 4 条（ZA-ADV-04/07、ZA-DIS-09、ZA-PRV-04）与 `human_review` 5 条（ZA-ADV-01/03/10、ZA-DIS-01、ZA-PRV-05），加上 14 条高风险 `rule_level`——虚假陈述（ZA-ADV-02/05）、诱饵与批准类陈述（ZA-ADV-08/09）、涂改商品说明（ZA-DIS-05）、促销竞赛（ZA-ADV-13）、POPIA 电子直销（ZA-PRV-02）、认证准入（ZA-ACC-01/02/03/05）、保修与合同条款（ZA-QUA-01/02/03）。其余 18 条 `rule_level` 可在「法条 + 页面原文」同时成立时自动出提示。

**是否具备开放条件：具备，但按「提示模式」上线**

- 可以自动出的（18 条，`rule_level` 且 `review_required=false`）：ZA-ECT-01~06（六条披露/冷却期/履行）、ZA-DIS-02/03/04/06/07/08、ZA-ADV-06/11/12、ZA-PRV-01/03、ZA-ACC-04。这些是**结构性/机械性**条目，误报率低。
- 只能提示、不能定性的：全部功效（substantiation）、价格（substantiation）、认证与准入、隐私、保修与条款类。
- 上线前必须解决的两个产品问题：
  1. **渠道判定**：报告必须先判断「页面是否在该站完成交易」，再决定引用 ECTA 还是 CPA。否则会像样例 FP1 那样误报价格缺失。
  2. **缺失≠违规**：认证与计量规则不能从「页面没写」推出「没做」，模板已固定为「页面未展示，需向商家核实」。
- 建议的 v0.2 优先级：① 补 `applies_when` 字段（解决 FP1）② 补 s.34/36 促销规则组 ③ 补「认证信息披露缺失」规则 ④ 拿到 ICASA 与 NRCS 的机关细则。

**不建议**：把 ZA 规则直接套到其他非洲市场。CPA 的「不合良心行为」「平实语言」、ECTA 的 17 项披露、以及 LOA 制度都是南非特有的组合。
